# Architecture Decision Records

Los ADR registran decisiones deliberadas que deben sobrevivir a sprints y refactors.

Estados usados:
- Proposed
- Accepted
- Accepted / Pending Implementation
- Accepted / Pending Full Coverage
- Superseded
- Rejected

Un ADR no prueba que la decision ya este implementada. Para eso consultar `current-state.md` y el codigo.
